What each column means
Column	Meaning
PassengerId	Unique row number for each passenger (just an ID)
Survived	The answer: 0 = died, 1 = survived
Pclass	Ticket class: 1 = first (richest), 2 = second, 3 = third
Name	Passenger's full name, including title (Mr, Mrs, etc.)
Sex	male / female
Age	Age in years (some missing)
SibSp	Number of siblings + spouses travelling with them
Parch	Number of parents + children travelling with them
Ticket	Ticket number (messy text, little use directly)
Fare	Price paid for the ticket
Cabin	Cabin number, e.g. C85 (mostly missing)
Embarked	Port where they boarded: S = Southampton, C = Cherbourg, Q = Queenstown
